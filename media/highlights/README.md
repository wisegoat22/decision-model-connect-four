The on-screen block labels describe verified effects on the board, not the model's private reasoning. A safe block requires no immediate own win, an opponent immediate winning placement before the move, and a chosen move that leaves no opponent immediate winning placement afterward. No piece placements or results were invented.

Every displayed model move has the same one-second cadence. Initial boards and final holds are presentation choices; playback does not measure inference speed. The excerpt skips the first 14 recorded moves explicitly. The two preset-opening games label the four initial pieces separately from model choices.
